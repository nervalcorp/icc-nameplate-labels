Nameplate Labels 4" × 5.5"
1 · Data no rows

Click a cell, then Ctrl+V to paste from Excel — it fills right and down from there. To replace the whole sheet, click a header cell (or Ctrl+A) and paste. Double-click or just type to edit; drag to select; Ctrl+C copies back out. Click a row number to select a row.

Raw text (tab-separated)

This always mirrors the grid, so it is current and copy-ready. Editing it does nothing until you press Read data, which replaces the sheet.

2 · Column mapping —

Fields for —. Each label type maps its own columns, so a shared FLA / RLA column can feed FLA here and RLA there.

3 · Serial numbers

Identical single-copy rows count as the same label. For several units of one model, use Copies — every copy gets its own serial.

4 · Artwork

The ICC blackout wordmark and the ETL Intertek mark are built in as the defaults. Empty slots print blank so nothing unapproved reaches a label.
